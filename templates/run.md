# 单次运行记录

| 字段 | 内容 |
|---|---|
| 实验卡 | 对应 EXP 编号与链接 |
| run ID | YYYYMMDDTHHMMSS-server-a-名称-seed50 |
| 服务器 | server-a / server-b |
| 状态与核对时间 | 计划中；时间与时区 |
| 开始 / 结束时间 | 待填写 |
| 代码仓库 / 分支 / commit | 待填写；branch 仅辅助，commit 或快照标识版本 |
| 含未提交改动 | 是 / 否 / 历史记录无法确认 |
| 实际运行源码快照或补丁 | 位置与 SHA-256；不要拿当前代码版本代替历史运行版本 |
| 协议与配置 | 路径、版本、哈希 |
| 数据版本与划分 | manifest 及哈希，样本数 |
| 条件 | seed、维度、目标、batch、预算等 |
| 启动命令与资源记录 | 脱敏命令或运行清单位置，PID/GPU/端口 |
| 原始结果目录 | 服务器别名 + 项目相对路径 |
| 可同步结果快照 | results 下的相对链接 |
| 完成或失败证据 | DONE / 状态 / 失败日志记录 |

## 指标与解释

注明验证或测试、方向聚合、单位、checkpoint 选择规则以及是否属于 smoke。

## 运行变更

追加停止、恢复、配置调整或交接事件。参数或数据变化造成不同实验条件时，新增 run ID，并关联前一次运行。
