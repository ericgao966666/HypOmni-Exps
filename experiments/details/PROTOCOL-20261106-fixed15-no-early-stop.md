# 固定15轮协议：5轮head＋10轮联合，无早停

[实验总览](../../README.md) · [测地线实验卡](../EXP-20261106-server-b-geodesic-fixed15.md) · [原生基线实验卡](../EXP-20261106-server-b-vast-init-baselines.md) · 更新：2026-11-06 UTC

本修订依据旧测地线验证曲线提出，用户明确要求**不进行早停**。每个条件固定完成总15轮/4830次更新，再按验证集选择模型。资源不足、数值异常或用户停止的保护机制仍保留；这些不属于基于验证成绩的早停，也不改变计划训练预算。

## 固定设置与改变范围

| 设置 | 本版 |
| --- | --- |
| 数据 | VAST train/val/test 82608/2048/2051及相同五测试集固定视听交集；相同caption、源视频划分和预处理 |
| 输入与种子 | 2帧、1音频窗、40文本token、无字幕、512D、seed50 |
| batch与步数 | global256，每轮322步；5轮head/1610步＋10轮joint/3220步，总4830步 |
| 早停 | 无；不会因为验证变差提前结束训练 |
| 学习率 | 保留旧9660步head/8050步joint日程的前15轮数值；峰值head1e-4、视觉5e-7、其他2e-5不变；不压缩cosine，不实施低LR消融 |
| 优化器 | AdamW(.9,.98)、矩阵WD=.01、梯度裁剪2；承接head的Adam/AMP/RNG，新解冻模块无旧optimizer历史 |
| 验证 | 每个联合epoch完整ITC、ITM和适用的几何指标；原生基线不硬套cone指标 |
| 测试 | 完成固定15轮后，使用验证选定的模型；测试成绩不参与选模 |

测地线沿用已选三组：K=.2/η=.7/α=0，K=.5/η=1/α=0，K=.1/η=.7/α=.05；λ=.2、半径(.21,4)、可学习c/τ与目标函数保持。继承已完成且校验通过的第5轮head完整状态，从原VAST主干/ITM重新进入联合阶段，不续训旧轮后期模型，也不重新搜索27组超参数。

原生VAST/GRAM/PMRL均从同一VAST checkpoint开始，重新执行各自5轮head＋10轮joint。它们保留各自原生对齐目标及1正2负ITM设计；几何方法保持1:1均匀异来源ITM。共同阶段和步数不能消除head结构、原生目标、ITM及几何超参数搜索预算差异。

## 验证选模

候选为总epoch6–15。所有条件先完成固定预算，才锁定选择并执行正式测试。

**检索主模型**：按验证双向平均ITM R@1最大、ITC R@1最大、epoch更早依次选择。原生三基线和测地线使用同一主规则。

**测地线双目标辅助模型**：同时满足以下条件后选择：

- ITM R@1距该run最佳值不超过0.5个百分点；ITC R@1距该run最佳值也不超过0.5个百分点。
- 困难负例合法入锥率不超过epoch5基准＋0.2pp，困难负例截断入锥率不超过基准＋0.5pp。
- 合格候选按正例合法入锥/全部、合法覆盖、ITM R@1、ITC R@1、更低困难错配、较早epoch排序。

若无候选满足约束，辅助模型显式回退到检索主模型，并标记 `balanced_eligible=false`，不能据此称“双目标成功”。几何评价统一原锥η_eval=1。阈值是工程规则，不是统计显著性，也不能代替全九边合法满足等严格诊断。

同时保存ITC最佳模型作诊断，末轮15模型保留供追溯。主结果不能把末轮与验证最优混写。

## 保存与空间

每轮保存全部指标、完整滚动恢复点，并生成可选模型。训练期间保留最佳ITM/ITC和当前模型；几何方案额外保留仍可能被未来阈值选中的双目标候选前沿。只有在两项检索与几何排序上被支配、或已永久落在递增检索门槛之外的本轮候选才可裁剪。随机序列和文件级回归检查要求：裁剪后选择与保留全历史权重的选择一致。

完成15轮并锁定模型后，保留检索主模型、适用的双目标辅助模型、ITC最佳及末轮15模型；本轮不再需要的中间权重和滚动优化器副本可以清理，指标与裁剪依据保留。旧实验的断点、里程碑及结果不删除。磁盘保护线40GiB、原子写锁和显存保护继续生效。

本机K=.2/.5先两组四卡并行；受当前数据盘预算限制，两者完成并收拢候选后接K=.1，空闲组可评估。原生基线目标端根据可用资源配置不重叠GPU组。资源等待不改变4830步固定预算。

## 输出与可比性

原生三基线各自的检索主模型在五个固定数据集测试，共15项。测地线三K分别报告检索主模型与双目标辅助模型，共最多30项记录；角色选中同一权重时复用已核验的同一测试分数并记录来源。

本版是在查看旧验证趋势后制定的探索性修订；不得将其称为预先独立确认的改进。所有新版正式测试结果尚待产生。缩短预算依据目前测地线趋势，尚未证明三种原生基线在15轮都已收敛；若其曲线在预算末仍上升，需要另记扩预算对照，不能静默延长本轮。单seed、既有测试集历史观察、不同结构和额外head搜索预算等限制继续保留。
