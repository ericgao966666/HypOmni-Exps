# 单次运行目录

新运行在 `runs/<实验编号>/<唯一run-id>.md` 建档，使用 [run 模板](../templates/run.md)。

每台服务器写自己的 run 文件；同一实验的主要结论汇总到 `experiments/` 对应卡片。这样两台机器可分别补充记录，减少同时改一张大表的冲突。

历史首批实验保留原项目的运行清单链接，不补造未知的开始时间、commit 或 PID。此目录目前只有规则，没有新增训练任务。
