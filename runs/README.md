# 本地运行记录

实际运行记录位于本地 `runs/<实验编号>/<唯一run-id>.md`，使用 [run 模板](../templates/run.md)。这些记录不再由 Git 跟踪，GitHub 只保留本说明。

运行命令、PID、GPU、重试、恢复、迁移和逐日状态留在本地。影响数据、训练预算、选模或可比性的变化仍须概括到 [实验主卡](../README.md)，保留失败和负结果。

已有 run 文件保持原位和原字节；当前训练状态只能以实际核对时间为准。新 clone 不会获得这些记录。首次从旧版本更新前，按 [同步说明](../SYNC.md) 备份并恢复，具体访问规则见 [本地证据说明](../LOCAL_ARTIFACTS.md)。
