## 评测与选模口径

- MSRVTT 训练/验证/测试为 7427/500/884；测试是音视频齐全的 884 个视频，不是完整 MSRVTT-1K。
- 64D，训练 seed50；T↔V、T↔A、V↔A 六方向等权平均，Recall 单位为 %，无 ITM 重排。
- 每方法按 500 样本验证集比较 R0/R1/R2/R3，再锁定方案及 checkpoint；测试不参与选择。每项最佳 epoch 指该方案微调阶段选中的轮次，不是完整训练预算。
- R0：10轮微调；R1：30轮微调；R2：10轮、提高头部学习率；R3：VAST 头部预训练后微调10轮。不同方法最终采用的训练预算不同，不能单独归因于几何。
- 所有结果仅一个训练种子，不报告跨种子显著性。各表按展示精度标记最优（加粗）与次优（下划线）。
