## 实验细节

### 数据、输入与优化


| 项目 | 实际设置 |
|---|---|
| 数据划分 | MSRVTT train/val/test=7427/500/884；本页31组共享相同数据 READY 与测试 ID 哈希 |
| 数据使用 | 本轮只在 MSRVTT 上更新参数；VAST 指预训练来源及原生基线模型，不代表本轮执行了 VAST 数据上的子集头预训练 |
| 视频 | 缓存 32 个均匀候选帧、短边 256；每次取 2 帧，输入 224×224 |
| 视频增强 | 训练分段随机取帧、随机方形裁剪（面积采样 0.8–1.0，失败回退中心方形裁剪）、0.5 概率翻转；评估固定取帧并 resize 到 224×224 |
| 音频 / 文本 | 本机音频源为 MP3，经固定缓存处理为 16 kHz、64 维 fbank，取 1 个 1024 帧窗口；文本最多 40 tokens。训练每视频每轮随机取一条 caption，验证/测试用第一条 |
| 采样 | 按视频/epoch/seed50 固定随机采样；全局 batch64，每轮打乱，丢弃不足一个全局 batch 的末尾，不补重复 ID |
| 预算 | 10 epochs；7427//64=116 步/轮，共 1160 步；不早停 |
| 优化器 | AdamW，betas=(0.9,0.98)，weight decay=0.01，梯度裁剪 norm=2 |
| 学习率 | 视觉编码器 5e-7；其余可训练参数含半径头最高 2e-5；5% 线性 warmup 后余弦衰减 |
| 更新范围 | 三个编码器共同微调；自有版本训练七个子集方向/半径头，原生基线按其实际可训练检索模块更新 |
| 精度 | CUDA autocast FP16；自有方向头 FP32、几何计算 FP64；非有限梯度使运行失败，不静默跳步 |
| 卡数 | VAST 各维度单卡；GRAM 16D 成功重跑单卡；本页64D五方法均单卡；其他主实验多数双卡。每组实际 world size 已写入 CSV/运行记录，所有组全局 batch 均为 64 |

原始协议：[28 组主体](../2026-10-20-server-b/provenance/protocol_main28.json)、[16D](../2026-10-20-server-b/provenance/protocol_d16.json)、[64D](../2026-10-20-server-b/provenance/protocol_d64.json)、[λ=1.0](../2026-10-20-server-b/provenance/protocol_lambda1.json)。数据哈希见 [MSRVTT READY](../2026-10-20-server-b/provenance/msrvtt_ready.json)。


### 本页保留的两个自有模型

两者共享VAST预训练编码器和同维度的七个子集头初始化。七种表示仍是T、V、A、TV、TA、VA、TVA；减少展示方法不改变模型内部的子集数量。对应模态pooled特征拼接、线性方向投影、方向归一化和可学习半径头；半径范围[0.21,4]，初始化r=1。

| 方法 | 对比距离 | 锥项 |
|---|---|---|
| 双曲 / hyp_cone | Lorentz双曲测地距离，曲率-1 | 主结果λ=0.1，K=0.1 |
| 欧氏 / euc_none | 欧氏距离（非平方距离） | λ=0；保留七个头与可学习半径 |

九组对比pair：T↔V、T↔A、V↔A；T↔VA、V↔TA、A↔TV；TV↔TVA、TA↔TVA、VA↔TVA。每组双向交叉熵后等权平均，温度0.07，全局64候选。双曲有锥另对T→TV、T→TA、V→TV、V→VA、A→TA、A→VA、TV→TVA、TA→TVA、VA→TVA九条同样本边计算锥罚项。

原生VAST/GRAM/PMRL使用各自目标；自有模型不额外加入原生基线的ITM等辅助损失。VAST/GRAM保留原生候选梯度分离约定，自有模型采用可微全局候选汇集。所有方法更新三个编码器；实际world size已保留在数据中，不能把全局batch相同解释为随机流逐步相同。

### 初始化与旧512D方案

对每个预训练模型家族，使用训练集归一化T/V/A特征的未中心化二阶矩拟合共同正交基，按维度取嵌套前导坐标。两个自有模型共用VAST家族的基；原生GRAM/PMRL各自拟合。**512D为恒等投影**。本轮重新构造七个子集头并重置半径为1，没有额外的VAST子集头预训练。

| 环节 | 旧512D进入MSRVTT前 | 本轮低维实验，包括512D |
|---|---|---|
| 数据与范围 | VAST冻结pooled特征；82611训练样本、batch256；编码器不更新 | 无此单独头部训练阶段 |
| 训练任务预算 | warmup8轮/2576步＋主训练30轮/9660步，共38轮/12236步 | 直接在MSRVTT联合训练10轮/1160步 |
| 实际导入MSRVTT的权重 | 主训练第22轮best（主训练7084步，之前另有2576步warmup） | VAST起点下重新构造的七头，半径r=1 |
| 学习率证据 | 基础协议warmup_lr=3e-4、head_lr=1e-4；后期记录5e-5 | 半径头与其他非视觉参数共用最高2e-5并余弦衰减 |

旧预训练任务的完成预算与选中checkpoint不同；旧VAST冻结测试用主训练第30轮last，旧MSRVTT来源为第22轮best。详见[新同步的checkpoint审计](../../EXP-004/2026-10-21/training/checkpoint_audit.json)和[旧微调来源](../../../experiments/EXP-006-msrvtt-finetune.md)。因此，新旧512D差异不能单独归因于维度。这里的训练初始化投影也不同于后文仅用于可视化的HoroPCA/CO-SNE。

### 执行与验证覆盖

- VAST温度除法前转FP32的数值修复属于实际运行源码；源代码版本以原版保存的文件哈希为准，不把基础Git commit当作全部运行内容。
- GRAM 16D首次双卡尝试触发进程显存上限，随后按用户要求单卡从头重跑、跳过新增预检；失败产物保留。本页使用成功重跑结果。
- 64D在用户明确要求停止预检后直接单卡训练，本页五方法均如此；没有完整64D GPU_READY。λ=1.0也按用户要求直接启动独立双卡训练，不声称通过了新的完整CPU/GPU预检。
- 七方法原记录中每一组均已完成预算；本页只作展示筛选。具体命令、PID、GPU、world size、源码/数据哈希及重试历史见[31组运行索引](run_index.md)，未新增运行。

这两组均属于本页保留的方法。λ=1.0为看到主结果后的探索性对照，与λ=0.1保持相同初始化、seed50、双卡、全局batch64和十轮预算，从头训练；不混入30组主结果排名。
