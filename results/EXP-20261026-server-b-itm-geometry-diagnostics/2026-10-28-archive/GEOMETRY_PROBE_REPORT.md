# 几何线性探针：来源判别与真实候选重排的差异

2026-10-26完成。这里只是原计划E4的几何单独可分性诊断，不是token ITM，也不是PMRL对照。原始数值见`geometry_probe_results.json`；对应数据目录`/data0/xiaobo.xia/yuxuan.gao/itm_hierarchy_20261026/geometry_probe_v1`中的protocol、checkpoint、归一化统计与DONE已保存。

两条件共享冻结的30轮九对ITC/九边entailment trunk、E1-u来源采样、同一seed50、1000步、batch96、零初始化45维线性头、AdamW LR0.01。仅改变36个非距离特征列是否启用；distance-only保留九条距离，其余置零。完整几何加入父/子半径、半径差与锥违反量。归一化仅用训练集4096条tuple；错配复合节点现场重算。候选与E0一致，2048条验证query全数计入分母。

原ITC-only为t→va **37.2559%**、va→t **37.0605%**，双向top32召回均84.2773%。完整几何相对距离的主任务平均R@1增加1.709个百分点，主要来自t→va的3.369个百分点，反向仅增加0.049个百分点；仍明显低于原ITC-only。没有跨seed噪声估计，不能把微小差异当成稳健收益。

结论边界：

- 高来源AUROC没有转化为固定困难候选的重排能力；只看随机来源负例会高估匹配效果。
- 没有观察到计划中特指的“112/121近乎完美、122明显更差”模式；这也不排除其他分布外识别捷径。
- 该结果不证明“层级有效”：完整特征同时含半径和锥量，没有单独识别其中的机制贡献。
- 该结果也不能否定几何作为token matcher辅助输入；那需要E4与无几何、distance-only、同容量零占位的真正配对实验。
- 下一步仍按计划先建立C0与E1/E2，再评估hard-negative采样及几何输入。不得用本探针代替完整ITM实验或与PMRL公平对比。
