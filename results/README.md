[manifest.json](manifest.json) 保存来源服务器别名、原始相对路径、采集时间、文件大小及 SHA-256。`source_root` 未填写或为 `workspace` 时，原始路径相对源工作区；为 `dataset_root` 时，相对源机器的数据根目录，具体路径见本机配置。原始产物按字节复制，保留原有 CSV 换行；由 PDF 渲染的显示预览另以 `derivation` 和 `source_sha256` 记录生成方法及源文件哈希。所有条目的 `sha256` 均校验所保存文件本身。历史 JSON 中的绝对路径是来源记录，不能假设另一台机器可直接访问。
